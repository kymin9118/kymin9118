## 🛠 Tech Stack & Skills

### Backend
- **Java / Spring Boot**: JPA/Hibernate ORM 설계, Spring Security 기반 인증/인가 구현, RESTful API 구축
- **Python / FastAPI**: 비동기(Async) API 개발, AI/LLM 서비스 연동 백엔드 파이프라인 구축

### Frontend
- **JavaScript (ES6+)**: 비동기 처리(Promise/async-await), DOM 제어 및 최신 문법 활용
- **React**: Component 중심 UI 설계, REST API 연동 및 상태 관리

### Database & Storage
- **Oracle**: PL/SQL 작성, 인덱스 설계 및 트랜잭션/권한 관리
- **MySQL**: 관계형 데이터베이스 정규화(1NF~BCNF), SQL 쿼리 최적화 및 인덱싱
- **Redis**: API 응답 캐싱 및 세션/토큰 관리

### Infrastructure & DevOps
- **Docker**: 컨테이너 기반 멀티 서비스 개발 및 배포 환경 구성 (Docker Compose)
- **AWS**: EC2, RDS, S3, ElastiCache를 활용한 클라우드 아키텍처 구축
- **CI/CD**: GitHub Actions를 활용한 빌드·배포 자동화

### AI & Data Engine
- **RAG & LLM**: Vector DB 및 LangChain/Ollama/PyTorch 기반 RAG 파이프라인 구축
